# Agent Guidelines for Muzzi

## Frontend Design & Development
For frontend tasks, read and follow `ai_agent_frontend_skill/SKILL.md` before planning or editing UI.
- Inspect existing components, tokens, and routes first.
- Follow the project's design system: Modern dark broadcast studio palette (Zinc neutrals, Indigo/Violet interactive accents, Emerald status cues).
- Avoid generic visual clichés (no placeholder images like placehold.co, no fake testimonials, no glowing cyan blobs).
- Build purposeful visual hierarchy, clean responsive layouts, accessible focus states, and deliberate empty/loading states.
- Always validate responsiveness and interaction flows before completing.
